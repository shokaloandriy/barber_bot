# Бот для барбера

Telegram-бот: графік дня, ручний і самостійний запис клієнтів, перенесення/скасування, закриття візиту з допродажем, фінанси, нагадування про візит і про наступну стрижку, база клієнтів з джерелами.

Стек: Python 3.12, aiogram 3, SQLite (aiosqlite). Один процес, polling, без зовнішніх сервісів.

## Що вміє

### Барбер (панель)
- **📅 Сьогодні** — записи на день з навігацією по днях, статуси: ⏳ чекає, 🟢 підтверджено, ✅ завершено, 🚫 не прийшов, 🔒 блок. Кнопка «⏰ Години цього дня».
- **🗓 Графік роботи** — тиждень, де кожен день — кнопка. За замовчуванням усі дні закриті: клієнти можуть записатись лише на дні, які барбер відкрив сам. Тап по дню → готові години (10–19, 12–21 …), «✍️ Свої години» (`10-19`) або «Вихідний». «🔁 Як минулого тижня» копіює години з попереднього тижня. Якщо записи випадають за нові години — бот попередить.
- **Картка запису** — підтвердити / відхилити, перенести, скасувати (з підтвердженням), «не прийшов», перейти до клієнта.
- **💈 Завершити візит** — 3 кроки: сума за послугу (кнопка з ціною прайсу або своє число) → допродаж (кнопки «Укладка», «Виривання воском» або текстом: `пудра 250`) → чайові (кнопки або число). Помилився — «✏️ Виправити суми» в картці запису.
- **➕ Запис** — пошук клієнта за імʼям/номером або новий клієнт → послуга → дата → вільний час (або «✍️ Свій час» / «✍️ Інша дата» поза графіком). Перетини блокуються.
- **🔒 Блок часу** — обід, особиста справа: `13:00-14:00 обід`.
- **👥 Клієнти** — статистика бази і джерел, пошук, картка (візити, сума, середній чек, неявки, останній/наступний візит, нотатка, індивідуальний інтервал нагадувань), історія, список «📞 Час на стрижку» (кому вже пора, з позначкою, кому бот нагадає сам, а кому треба подзвонити), експорт CSV для Excel.
- **💰 Фінанси** — один екран: скільки заробив за цей тиждень і цей місяць, розбито на ✂️ послуги, 🛍 допродаж і 💸 чайові (з деталями по позиціях). Кнопка — минулий тиждень і місяць.
- **⚙️ Налаштування** — послуги і ціни, позиції допродажу, контакти, графік роботи, нагадування, параметри запису, розсилка, посилання з мітками джерел.

Стартовий прайс: стрижка 700 грн (45 хв), стрижка + борода 900 грн (60 хв), дитяча 600 грн (30 хв), під насадку 600 грн (30 хв); допродаж: укладка 600 грн, виривання воском 50 грн. Змінюється в ⚙️ Налаштування.

### Клієнт
- **✂️ Записатися** — при першому записі ділиться номером (кнопкою або текстом) → послуга (минула позначена ⭐) → дні, де реально є вільне вікно → час → підтвердження. Заявка йде барберу на ✅/❌, клієнт отримує відповідь.
- **📋 Мої записи** — перенести або скасувати (барбер отримує сповіщення).
- **💈 Послуги і ціни**, **📍 Контакти**.

### Автоматика (раз на хвилину)
- За 24 год і за 2 год до візиту — нагадування клієнту з кнопками «Буду / Перенести / Скасувати».
- «Пора на стрижку» — через N днів після останнього завершеного візиту (стандарт 28 = 4 тижні, можна задати окремо для клієнта), один раз на цикл, лише якщо клієнт ще не записаний. Клієнт може вимкнути.
- 08:30 — барберу план дня, кількість непідтверджених заявок і попередження, якщо на тиждень уперед не відкрито жодного робочого дня.
- 21:00 — список незакритих візитів (щоб фінанси і нагадування були точними).
- Нові підписники бота приходять барберу сповіщенням з джерелом.

### Пасивна база
- Кожен, хто натиснув /start, потрапляє в базу з джерелом (`t.me/бот?start=insta`, `qr`, `tiktok` …).
- Якщо барбер вніс клієнта вручну, а потім цей клієнт зайшов у бот і поділився тим самим номером — картки зливаються, історія зберігається.

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# source .venv/Scripts/activate  # Windows (Git Bash)
# .venv\Scripts\Activate.ps1     # Windows (PowerShell)
pip install -r requirements.txt
cp .env.example .env   # встав BOT_TOKEN, DB_PATH=barber.db
python bot.py
```

Свій Telegram ID: напиши боту `/id`, впиши в `ADMIN_IDS`, перезапусти.

## Деплой на Railway

1. Залий папку в GitHub-репозиторій → Railway → New Project → Deploy from GitHub.
2. **Volume**: сервіс → Settings → Volumes → Add Volume, mount path `/data`. Без цього база зникатиме при кожному деплої.
3. **Variables**: `BOT_TOKEN`, `ADMIN_IDS`, `DB_PATH=/data/barber.db`, `TZ_NAME=Europe/Kyiv`.
4. Старт-команда вже в `railway.json` (`python bot.py`). Публічний домен не потрібен — бот працює через polling.
5. Після першого запуску: барбер пише боту `/start`, далі **🗓 Графік роботи** — відкрити робочі дні (без цього клієнти не побачать вільного часу).

## Структура

```
bot.py              запуск, порядок роутерів
config.py           змінні середовища
db.py               схема, міграції (_ensure_column), дефолтні дані, налаштування
utils.py            час, парсинг, вільні слоти, перетини, клієнти, відправка
views.py            тексти й клавіатури екранів
cb.py               callback-data і стани FSM
keyboards.py        reply-меню
scheduler.py        нагадування і щоденні звіти
handlers/
  common.py         /start, меню, скасування, fallback
  booking.py        спільний потік послуга → дата → час (4 сценарії)
  admin_book.py     ручний запис барбером
  admin_schedule.py графік роботи, день, картка запису, закриття візиту, блок
  admin_clients.py  база клієнтів
  admin_finance.py  фінанси (тиждень / місяць)
  admin_settings.py послуги, допродаж, контакти, розсилка, посилання
  client.py         клієнтська частина
```

## Обмеження, про які треба знати

- **Один барбер.** Для кількох майстрів потрібна таблиця `masters` і `master_id` у записах і годинах.
- **Стани діалогів у памʼяті.** Якщо Railway перезапустить бот посеред запису, користувач просто почне заново (кнопка підкаже). Дані в БД не втрачаються.
- **Відхилення перенесення** від клієнта скасовує запис повністю (клієнт отримує кнопку «Обрати інший час»), а не повертає старий час.
- **Без онлайн-оплати і передоплати** — неявки лише рахуються в картці клієнта.
- Нові колонки в БД додавай через `_ensure_column` у `db._migrate()`, а не правкою `SCHEMA` — інакше існуюча база на volume їх не отримає.
